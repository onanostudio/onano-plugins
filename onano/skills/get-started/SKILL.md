# Getting started with Onano Studio

1. **Check the connection.** Call `onano_health`. If it answers, Onano Studio is installed and its
   engine is running: say so in one line and go to step 3.
2. **No onano tools, or they fail to start?** Onano Studio is not installed on this computer yet.
   - Download it free from https://onano.app/download (Windows 10 and 11).
   - Install it and open it once.
   - Restart Claude Code or Codex so the tools load.
   Studio is Windows only for now; on a Mac, say so honestly.
3. **Open Studio's window** for editing. The file tools (transcribe, cut, find silences) work
   without it; anything on the timeline needs the window open.
4. **Offer a first thing to try**, one line each, and let them pick:
   - "Turn my latest recording into three shorts with captions."
   - "Take out the pauses and the ums."
   - "Make a title card for the start."

Then follow the onano-video-editing skill.
